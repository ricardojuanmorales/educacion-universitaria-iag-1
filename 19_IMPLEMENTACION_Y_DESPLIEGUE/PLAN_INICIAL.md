# Ruta de implementación

1. Elegir primera necesidad educativa/investigativa verificable.
2. Definir spec SDD breve con propósito, personas, datos, riesgos, criterios, pruebas y revisión humana según AI StoryLab 1.
3. Prototipar aplicación modular.
4. Evaluar privacidad local-first, portafolio y roundtrip.
5. Proponer ensamblaje en portal común por subrutas y GitHub Actions, sujeto a gate de publicación separado, siguiendo Materia Mundi.

No se ha desplegado ninguna aplicación por este acto.
